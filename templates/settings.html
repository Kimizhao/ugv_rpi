首次使用此云台时，您需要按照以下步骤配置舵机 ID 和中位：

俯仰舵机 ID: 1平移舵机 ID: 2

俯仰舵机和平移舵机的默认 ID 初始都为 1，但平移舵机的 ID 需要设置为 2

1

断开俯仰舵机的连线，确保您正在设置平移舵机的 ID。

2

点击 [设置平移 ID] 按钮将当前舵机配置为平移舵机，这将把平移舵机的 ID 设置为 2。

设置平移 ID
3

然后您可以将俯仰舵机的连线重新连接到云台上。

4

现在我们可以开始设置中位，点击 [释放] 按钮解锁两个舵机的扭矩锁。

释放
5

如下图所示，手动调整两个舵机的角度，使摄像头指向正前方。

6

点击 [设置中位] 按钮将当前位置设置为中位。

设置中位
7

然后您可以开始测试云台转动到不同角度，检查其是否正常工作。

8

如果云台工作不正常，您可以尝试重新进行整个过程。

注意：如果您在第 1 步没有断开俯仰舵机，点击 [设置平移 ID] 按钮后，两个舵机的 ID 都会被设置为 2。在这种情况下，您需要点击 [设置俯仰 ID] 将两个舵机 ID 恢复为 1，然后重复整个设置过程！

设置俯仰 ID
